## 사용 방법

실행 중인 게임을 종료한 뒤 기존 런처의 **업데이트 확인 → 설치·업데이트 → 게임 시작**을 사용한다. 런처 자체를 다시 설치할 필요는 없다.

- **CC대 학생들 → 비밀 메모**: 다섯 인물 모두 01/02/03을 열람한다. 03의 HAPPY/BAD/SECRET 본문도 모두 확인할 수 있다.
- 사진 뒷면·스티커의 기존 숨겨진 문구도 테스트 미리보기로 확인한다.
- **갤러리**: 준비된 일러스트를 플레이 기록 없이 열고, 묶인 표정 컷을 버튼이나 화면 클릭으로 넘긴다.
- 앞선0.6.7의 **챕터 선택 → 여기서부터 읽기**도 포함한다. 개별 루트01→06과 엔딩까지 같은 테스트 안에서 이어지고 선택·이름·호감도·메시지가 유지된다.

## 기록을 유지하는 방식

실제 획득 판정을 덮어쓰지 않고 UI용 열람 함수를 추가했다. `cg_seen`, `cg_unlock`, `cg_start`와 비밀 메모의 실제 준비/획득/엔딩 판정 등 기존 핵심 함수13개는 변경 전과 동일하다. 갤러리를 보거나 메모 탭을 여는 것으로 엔딩·수집 기록이나 점수를 만들지 않는다. 실제 플레이에서 새 메모/CG를 얻는 동작은 정상적으로 기록한다.

현재 `define CAMPUS_TEST_BUILD = True`가 전체 열람을 켠다. 정식판 준비 때 False로 바꾸고 다시 컴파일하면 실제 획득 조건에 따른 잠금이 복구된다. 미리보기를 위해 생성한 가짜 해금 기록은 없다. 시크릿 그림을 감상하는 것과 시크릿 스토리 진입은 별개이며, 스토리의 해피 엔딩 조건은 유지한다.
