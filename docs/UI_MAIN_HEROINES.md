## 메인 화면

`renpy_project/game/screens_campus_main.rpy`가 `init offset = 900`에서 메인 화면만 덮어씁니다. 기존 대사창·학생증의 비밀 시스템·SD 전체 컷 시스템은 바꾸지 않습니다.

- 상단 중앙: 정돈된 명조 로고와 짧은 기존 부제.
- 중앙: 대표 일러스트 한 장. 인물·포즈는 게임에서 합성하지 않습니다.
- 하단 중앙: `게임 시작 / 불러오기 / 갤러리 / 히로인 설명 / 엔딩 / 옵션` 2열×3행.
- 이어하기·종료는 작은 상단 보조 항목이며, 개발실은 개발 모드에서만 보입니다.
- 버튼은 이동·확대 없이 옅은 하늘색 hover와 잉크 색 변화만 사용합니다.

밝은 아이보리 `#fffefb`, 흰빛 `#fbfdff`, 옅은 하늘 `#e6f2f6`, 청회색 잉크 `#3c596b`, 부드러운 강조 `#287388`을 사용합니다. 본문·조작은 Noto Sans KR(`CAMPUS_BODY_FONT`), 로고·이름은 Noto Serif KR(`CAMPUS_TITLE_FONT`), 작은 장식 손메모만 개구 Regular(`CAMPUS_NOTE_FONT`)입니다. 경로와 공통 기본값은 `game/typography.rpy`에서 관리합니다.

## 메인 비주얼 교체

권장 1920×1080 WebP 또는 PNG 완성 컷입니다. 갤러리 등록표의 `ld_01` 경로가 우선이며, 등록표가 없는 단독 사용에서도 `images/cg/ld_01_main_visual.webp` 또는 같은 PNG를 찾습니다. 없으면 기존 캠퍼스 배경과 작은 준비 문구로 표시합니다. 캐릭터 그림이나 최종 CG를 이번 작업에서 생성하지 않았습니다.

그림은 2026-11-04 사용자 스케치에 따라 다섯 히로인이 같은 흰색 프릴 드레스를 입고 햇빛 아래 잔디밭에 나란히 누운 구도로 완성했습니다. 왼쪽부터 로만·시아·오므·다림·루미이며 주인공은 등장하지 않습니다. `images/cg/ld_01_main_visual.webp`를 사용하고, 상단 로고(y=60~190)와 하단 메뉴(x=530~1390, y=815~1040) 사이로 다섯 얼굴이 보입니다. 완성 그림이 있어 준비 문구는 표시되지 않습니다. 메인 화면 방문 시 `cg_unlock("ld_01")`을 호출하며 실제 획득·표시 규칙은 갤러리 시스템이 관리합니다. 원본·프롬프트는 `artwork/title_backgrounds_20261104/`에 보존했습니다.

## 히로인 설명

메뉴는 기존 `profiles` 화면을 사용합니다. 다섯 캐릭터 사진·이름·나이·학년·학과·MBTI·취향·소개·스티커 상호작용·앞뒷면·세 장의 잠긴 메모와 해금 조건을 유지했습니다. 기본 정보와 소개는 실제 노트의 48px 줄에 맞춥니다. 앞면 소개 아래에 덧붙였던 인용문과 바깥 손메모를 제거하고, 기존 캐릭터 한마디(`HEROINES[key]["intro"]`)는 뒷면에 유지합니다. 상단 세 탭·학과 배지·앞뒷면 버튼은 보이는 배경과 글자의 양축 중심을 맞춥니다. 새 캐릭터 설정·대사는 만들지 않았습니다.

소개글과 긴 비밀 메모는 노트·팝업 안에서 스크롤하며 본문을 줄여 없애지 않습니다. 사진은 기존 `diary_photo()`의 교체·누락 대체 경로를 그대로 사용합니다. 상세 교체 방법은 `README_profile_ui.md`를 따르세요.

## 검증 범위

이 문서는 구현 구조와 자산 교체 안내입니다. Ren’Py 실행, 다섯 소개의 긴 문장 줄바꿈, 창 크기별 메뉴·로고·사진 안전 영역, CG 교체·해금·저장의 실제 검증 범위는 [VERIFICATION_0.3.0.md](../tests/VERIFICATION_0.3.0.md)를 기준으로 확인합니다. 소스 UI의 SDK 네이티브 검증은 완료했습니다. 배포판은 사용자 요청으로 보류하며, 공식 챕터 QA 종료 단계와 독립 EXE 클릭의 미검증 범위는 같은 보고서에 구분합니다.
