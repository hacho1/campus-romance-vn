# 시아 S01–S02 · 확정 원고 반영

입력 원고는 사용자 폴더의 `시아 R01 스토리.txt`와 `시아 R02 스토리.txt`다. 파일 이름은 R01/R02이지만 본문 표기와 요청을 따라 게임에서는 **S01/S02**로 구분한다. 원본 바이트를 `D:\CampusRomance_VN\design_docs\story_sources\sia_s01.txt`, `sia_s02.txt`에 보존했다. R03–R06 원고는 읽거나 반영하지 않았다.

## 반영 범위

- S01 「내 웹툰의 첫 번째 독자」: 8씬·대사/서술 663개·선택지1개/3갈래.
- S02 「너랑 있으면 이상하게 재밌어」: 8씬·대사/서술 892개·선택지2개/6갈래.
- S01 새 웹툰 원고·점심·창작에 관한 대화·피드백·다음 약속을 그대로 반영했다.
- S02 리듬 게임 패배, 인형 뽑기/이름, 포토부스, 식사, 오므와의 우연한 만남, 가벼운 질투, 산책, 시아 단독 시점을 그대로 반영했다.
- CH07에서 시아를 직접 선택하면 `route_sia → sia_s01 → sia_s02`로 연결한다. 점수로 다른 인물로 바꾸지 않는다.
- S02 후에는 `sia_route_preview_end → chapters_demo_end`로 이동하며 저장/메뉴 버튼이 있는 준비 중 화면을 표시한다. S03으로 진입하거나 시아 엔딩을 해금하지 않는다.

`SCENE 05`의 원고 형식은 다른 장면과 달리 `# S01 SC05 · …`였으므로 이 표기도 실제 SC05로 처리했다. 원고에 붙은 HTML/WritingBlock, 장면 개요, 편집 설명은 대사가 아니다. 해당 내용은 SOURCE/CONTI 주석이나 감사 기록으로 구분했고 실제 대사와 선택지 문구는 바꾸지 않았다. 챕터 완료/다음 편 카드 문구도 정식 대사로 발화시키지 않는다.

## 점수·기억

시아 점수 정책은 `game/data/sia_relationship_choices.json`에 별도로 둔다. 모든 점수는 실제 **5 또는 10점**이며 1/2점에 배율을 곱하는 방식이 아니다.

| 선택 | 해피 | 배드 |
| --- | --- | --- |
| S01 마지막 컷 A · 구체적인 감정 피드백 | +5 | 0 |
| S01 마지막 컷 B · 유머와 개선 의견 | +5 | 0 |
| S01 마지막 컷 C · 작가 의도에 대한 대화 | +10 | 0 |
| S02 인형 이름 A/B/C | 0 | 0 |
| S02 식사 A · 함께 있는 즐거움 | +5 | 0 |
| S02 식사 B · 진지한 창작자 모습 인정 | +10 | 0 |
| S02 식사 C · 솔직한 편안함 표현 | +5 | 0 |

인형 이름은 `sia_s02_cat_name`으로만 남긴다. 원고의 `sia_affection`, `sia_mutual_trust` 증가는 주석으로 보존하고 신뢰도 변수를 새로 만들지 않았다. 해당 선택의 의미를 위 정책으로 재분류했다. 창작 자신감 같은 별도 이야기 카운터·기억 플래그는 호감도와 중복 합산하지 않는다. 본격적 갈등 전의 내용이므로 배드 선택을 억지로 추가하지 않았다.

NOTE01은 시아 루트 진입 시, NOTE02는 S02 개인 데이트 완료 시 열린다. NOTE03/시크릿은 새로 해금하지 않는다. 진행 기록에는 `sia_s01`, `sia_s02` 완료 키를 보존한다.

## 그림·음악과 휴대폰

새 스탠딩·SD·CG를 넣지 않은 대사/콘티 단계다. 원고의 LD 표정, 권장 SD, 포토부스 CG 후보는 SOURCE/CONTI에 남겼다. 기존 배경/BGM/효과음을 재사용하며 새 미디어를 만들지 않았다. 게임센터는 기존 게임 체험 배경, 포토부스는 기존 카페, 시아의 방은 기존 방 배경을 임시 사용한다. 확정 배경·일러스트 작업은 이후 교체 가능하다.

전화 시간표는 `S01/S02`와 내부 챕터번호201/202를 사용한다. 로만 R01/R02와 충돌하지 않는다. 명시된 시각은 원고 그대로 쓰고, 시각이 없는 장면은 문서화한 연출 기본 시각을 사용한다. S01은 같은 원고 감상일, S02는 이후 토요일로 분리하며 이전 기록은 남긴다. 시아 시점은 기존 시점 표시 UI를 재사용한다. 시아 시점에서 되읽는 문장은 새로 전송한 메시지로 추가하지 않는다.

## 파일과 검증 기록

- `tools/import_sia_first.py --write`: 두 보존 원고에서 두 route와 시아 정책/감사만 다시 생성한다. 다른 route는 생성하지 않는다.
- `game/routes/sia_s01.rpy`, `sia_s02.rpy`: 게임용 대본. 각 SOURCE 행은 원본 행에 대응한다.
- `game/systems/sia_story_runtime.rpy`: 진입/완료·임시 배경·준비 중 연결.
- `tools/import_roman_first.py --phone-cues`: 대사를 재생성하지 않고 전체 전화 시간표만 다시 계산한다. S01/S02 지원 추가.
- `game/systems/test_chapters.rpy`, `game/screens_test_chapters.rpy`: 시아 테스트 탭2개.
- `game/screens_story_stage.rpy`: S02 전용 완료 문구와 기록 저장 버튼.
- `docs/SIA_IMPORT_AUDIT.json`: 원고 SHA·각 대사/선택·연출/효과 기록. 1,555개 대사/서술과 9개 선택지가 원고 입력에 대응하며 원본 복사 SHA 일치·8씬/8씬을 정적으로 확인했다.

네이티브 실행, 저장/불러오기, 기존 세이브 이전과 새 점수의 실제 검증은 상위 작업의 통합 검사에서 수행하며 이 문서의 정적 결과만으로 실행 통과를 주장하지 않는다.

원고를 다시 가져올 때는 `import_sia_first.py --write` 후 `import_roman_first.py --phone-cues`를 순서대로 실행해야 한다. 뒤 명령은 S01/S02의 장면별 시간·시점·구버전 저장 위치 조회표를 최종 대본 행 번호에 맞춰 등록한다.
