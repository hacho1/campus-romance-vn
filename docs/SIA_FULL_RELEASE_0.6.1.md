## 원고를 게임으로 옮긴 기준

- 화자·원문 행·대사 순서를 남기고 편집 설명/HTML/WritingBlock은 실제 대사와 구분했다.
- S05에 중복 표기된 CHOICE 번호는 파일에서 등장한 순서로 ID를 부여했다. 선택 문구는 바꾸지 않았다.
- 원고의 조건·ELSE·공통 복귀를 실제 분기로 옮겼다. S05의 이미 갈등을 해결한 경로는 참석 약속이 본문에 있어 지원 상태를 무보상 `attend`로 기록한다.
- 미전송 작성 중 문장은 휴대폰의 발송 기록에 추가하지 않고 원문 그대로 대사창에 보여준다. 조별 과제 채팅은 축제 준비팀과 별도 방으로 나누고 팀원 A/B를 실제 발신자 이름으로 기록한다. 히로인 시점·시간·날짜 구분은 기존 휴대폰 시스템으로 처리한다.
- 실제 시각이 명시되면 원고를 사용한다. 시각이 없는 장면은 연출 기본값이며 실제 달력 날짜나 현재 PC 시각을 뜻하지 않는다. 날짜 순서는 이야기 내부 ID다.
- 스탠딩·표정·미제작 LD/SD는 SOURCE/CONTI로 표시했다. 새로운 캐릭터 그림이나 배경·음악을 생성하지 않았고 가용 배경/음악을 임시로 재사용한다.

## 호감도와 엔딩

실제 보상은 **0·5·10점**이다. 해피·배드는 독립적으로 누적하고 기존 신뢰도는 합산하지 않는다. 기존 시아 선택 9개는 그대로 두고 신규 32개를 추가해 시아 정책은 41개다. 취향이나 시크릿의 장난 선택에는 억지 점수를 붙이지 않는다.

S06은 S01~S06의 현재 플레이 선택과 실제 회복 행동을 평가한다. 공통 루트의 호의적인 선택만으로 시아 개별 루트의 반복 회피를 없애지 않는다. 화면의 누적 게이지를 초기화하거나 깎지 않는다.

반복 회피가 충분하고 마지막에도 회피하면 배드로 이어진다. 실제로 대화를 나누고 회복한 뒤 한 번 소극적으로 답했다고 배드가 되지는 않는다. 회복이 필요한 중간 상태는 새 대사를 만들지 않고 원문 SC05-H의 관계 회복 대화로 이어지며, 그 대화가 끝난 사실을 확인한 뒤 해피 후반으로 간다. 세부 조건·달성 가능한 경로는 `SIA_RELATIONSHIP_POLICY_061.md`에 기록한다.

## 검증과 공개

새 버전의 실제 Ren'Py 실행 **9케이스·21개 검증·13개 확인 지점 전부 통과**했다. S03~S06 실제 메뉴 진행→해피, 실제 배드 경로, 원문의 H05 관계 회복 대화, 엔딩 화면의 시크릿 Replay 버튼, 처음 시크릿 CG가 표시되지만 미수집인 상태→완료 후 양 탭에 한 작품으로 수집, Replay 후 기존 점수·휴대폰·플레이 상태 복귀, 실제 선택의 롤백·재적용·저장/불러오기를 확인했다.

서명된 실제 공개 **0.6.0/build2026110902**에서 만든 두 저장으로 새 버전의 이어하기를 검증했다. 완료 메뉴 저장은 같은 위치·상태로 복원하고 S03 이어가기 버튼으로 진행했다. 옛 준비 중 독백에서 만든 실제 저장은 불러오면 S03 첫 대사 「토요일 아침.」으로 직접 이어졌다. 두 경우 모두 해피20·배드0, 선택/보상 ID, 인형 이름 `천재냥`, 기존 메시지5개의 시간·날짜를 포함한 이력, 수집 기록이 유지됐다. 현재 표시 시각은 S03에 맞게 오전10시·「S02 이후 닷새 · 토요일」로 바뀌었다. 따라서 모든 저장이 옛 준비 중 문장에 멈춘다고 주장하지 않는다.

Lint 오류·경고 없이 통과했다. 신규 대사3,753개·32개 선택 결과·22개 조건과 기존 S01/S02의1,555개 대사는 독립 원고 대조를 통과했다. 정책 검사는 실제 플레이와 구분해, 524,880개 유효 선택 경로와 88,200개 경계 입력을 순수 함수로 검사했다.

실행은 D의 격리 복사본과 QA 저장 폴더, SDL dummy/software 표시를 사용했다. 실제 사용자의 현재 게임이나 마우스·포커스를 조작하지 않았다. 모든 선택 조합을 그래픽으로 처음부터 끝까지 전수 플레이하거나 실제 GPU와 전체 온라인 설치를 검증했다고 주장하지 않는다. 로그·화면·상세 결과는 `tests/sia_full_061`에 있다. 추가한 조별 과제 방의 실제 팀원 A/B/A 메시지3개, 발신자·시각·별도 방, 단체 대화 부제와 하단 중복 없음도 확인했다. 최종 원본477파일과 검증본의 SHA가 같고 실제 사용자 저장14개의 SHA·수정 시간이 그대로였다.

**0.6.1-test / build2026110903**를 기존 공개 채널에 활성화했다. manifest SHA256 `5deae162171e6cecc5529e61a5b26f6a213ea8282a2d0896029d56fc859caa18`, 전체1,854파일·582,693,162바이트다. 새61조각·2,368,964바이트만 업로드하고 기존1,791조각을 재사용했다. Windows ZIP이나 새 런처 EXE는 만들지 않았다.

게시 후 production CLI(qa:false), 고정 RSA 서명·공지5개, 공개11파일 실제 다운로드와 배포본 SHA 대조를 모두 통과했다. 정책41개/기존9개 보존/시크릿무보상/CG 선행 해피·완료 후 수집/별도 과제 방도 공개 데이터로 확인했다. 시크릿 PNG는 이전과 같은 원본 해시를 유지했다. 전체 게임을 사용자의 PC에 다시 설치한 검사는 아니다.
