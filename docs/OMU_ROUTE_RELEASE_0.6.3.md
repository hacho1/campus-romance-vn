# 오므 1~6장·시크릿 반영 · 0.6.3-test

기준 원본: `D:\CampusRomance_VN\renpy_project`.
첨부 파일명 R01~R06은 원고 본문의 **O01~O06** 이름으로 게임에 연결했다. 전체 루트 제목은 「네가 찍힌 풍경」이다. 사용자 요청대로 **오므 개인 루트에 스탠딩을 넣지 않았다.** 기존 공통 루트의 오므 스탠딩과 다른 인물의 기존 연출은 유지한다.

## 그림과 스탠딩

오므 시작/배경 전환/시크릿/종료에서 `story_stage_visible=False`와 빈 캐스트를 유지한다. 원고의 LD·표정·SD 지시는 SOURCE/CONTI로 보존한다. 스탠딩을 생성하거나 배치하지 않았다. 전용 배경이 없는 장소에는 기존 배경을 임시로 쓰며 장소 이름은 원문을 표시한다.

첨부 그림은 `game/images/cg/endings/omu_secret.png`에 원본 그대로 저장했다. **2048×1152·2,407,940바이트**, SHA256 `c21b463c2d9d3c84ff471c6b174859792bc153543eddc1e9bf0ebaa2b9712716`이다. 생성·보정·크롭·확대는 하지 않았다.

시크릿 SC02의 CG MAIN(원문302행)에서 그림이 나오고, SC03의 새 배경(565행)에서 내린다. 표정 차분은 미제작 콘티로 남겼다. 최초 시크릿 플레이에도 그림은 표시되지만, 갤러리는 시크릿 완료 뒤에 OMU/ENDING의 한 작품으로 해금된다. 해피 이전에는 시크릿과 CG 표시를 잠근다.

## 호감도·분기·휴대폰

- 기존과 같은 독립 해피/배드 **0·5·10점**이다. 오므 전용50개 정책을 별도 JSON으로 관리하고, 시크릿3선택은0점이다.
- 원고 지시에 따라 오므 개인 루트와 공통 루트 중 오므 본인에게 부여된 선택만 판정에 쓴다. 다른 히로인의 점수나 신뢰도를 합산하지 않는다.
- O03의 요약표와 개별 메뉴 수치가 달라 실제 메뉴의 명시된5/10을 보존했다. 개별 루트 원시 최대 해피115는 게이지100상한으로 표시되고 배드는50까지다.
- 반복된 미해결 경계 갈등과 실제 회복 행동, 마지막 선택을 함께 평가한다. 중간 상태는 원문 H05의 상호 계획 대화를 실제로 진행한 뒤 회복을 확인한다. 시크릿에 점수를 추가하지 않는다.
- 배드의 사고사는 원문에 있는 비극적 대체 전개다. 사고가 선택의 벌이나 점수의 직접적인 결과라고 덧붙이지 않았다. 판정 기준·달성 가능한 경로는 `OMU_RELATIONSHIP_POLICY_063.md`에 있다.
- O03의 작성 중 문장은 대사창에서 초안으로 보이고 실제 전송 지점에서 한 번만 발송한다. 나머지 미전송 초안은 채팅 이력에 추가하지 않는다. 전화 속 목소리는 메시지로 기록하지 않는다.
- 사진 동아리는 별도 `omu_photo_club` 방과 담당 발신자를 사용한다. 기존 시아 과제방·축제 준비팀과 섞지 않고 단체 대화로 표시한다. 오므 시점에서는 오므가 오른쪽, 주인공이 왼쪽이다.
- 원고의 명시 시각과 이야기 날짜를 연결했다. 시각/달력 날짜가 없는 부분의 연출 기본값은 실제 달력이나 PC 현재 시간이라는 뜻이 아니다.

## 실행·저장·공개 검증

공식 Ren'Py 8.5.3에서 신규 **13케이스·40개 명시 검증·21개 고유 테스트 훅**이 통과했다. 공개 0.6.2에서 실제 저장을 만드는 기준 검사도 별도 **3케이스·6검증** 통과했다. 최종 Lint는 오류·경고가 없다.

- 실제 CH07 오므 선택→O01~O06의 전체 해피 경로, 배드 경로, H05 회복 완료를 실행했다.
- 엔딩 화면의 실제 시크릿 Replay 버튼, 첫 CG 표시 전 미수집/완료 후 단일 작품 해금과 호출 화면의 점수·선택·폰 복원을 확인했다.
- O03 초안→명시 전송1회→주인공 답장2개, O04 독립 단체방·담당2메시지·미전송 초안, O05 미전송 초안을 확인했다. 시점에 맞는 좌우·작중 시각/날짜를 사용하며 PC 현재 시각을 쓰지 않는다.
- 새 O04 저장/불러오기, O01 선택 롤백의 0→10→0→10을 확인했다. 공개 0.6.2의 시아 S03·공통 CH06·오므 선택 대기 저장을 불러와 기존 Say와 기록을 보존했고, 대기 저장의 O01 이어가기 버튼도 확인했다.
- 실제 사용자 기록 **14개는 SHA256와 수정시간이 그대로다.** 공통/로만/시아 등 기존26개 루트 원문, 기존 공통/시아 정책은 백업과 바이트가 같다.
- 테스트 사본의 소스·에셋 **488개와 제품이 일치**하고, 배포 snapshot도 같은488개 해시가 일치한다. 이전 공개판67개 RPYC 이름 정보를 공식 컴파일에 반영했으며 이번 공개본76개를 `launcher_publish/compiled_seeds/2026110905`에 보존했다.

실행 증거와 스크린샷 목록은 `tests/omu_route_063/RESULT.json`, `README.md`, `native_results.json`에 있다. 초기 테스트 하네스의 skip/위젯 조회/CG 관측 가정은 하네스에서 수정했고 제품 오류로 집계하지 않았다. 모든 선택 조합을 화면으로 실행한 것은 아니며, 전체 원문·50정책 대조와 대표 전체 해피 및 집중 배드/회복 경로를 결합했다. 전경과 커서를 보존하는 headless 실행으로 검사했으며 음향의 청감 품질은 이번 범위가 아니다.

### 온라인 배포

기존 공개 채널 <https://campus-romance-playtest.naiski.chatgpt.site/>에 **0.6.3-test / build2026110905**를 활성화했다. 새71조각·5,305,677바이트를 올리고 기존1,792조각을 재사용했다. 전체1,865파일·585,647,171바이트이며 manifest SHA256은 `43e4f7457c68c293326cf52f3e6abee59aa11bc78432ed24e314fe8e2870705c`다.

QA override 없는 실제 production CLI가 위 버전/build를 확인했다. 고정 RSA 서명·공지5개와 대표16파일의 실제 HTTPS 다운로드 SHA256가 snapshot과 일치한다. 첨부 PNG는 C의 원본·D의 제품·snapshot·공개본까지 동일하며, 기존 시아 CG 등록과 기존 그림도 유지된다. 근거는 `tests/omu_route_063_public/RESULT.json`이다.

Site/런처 EXE는 게임 내용 변경만을 위해 다시 만들지 않았다. 사이트·런처의 최신 버전/공지는 활성 manifest에서 읽는다. 기존 런처에서 **업데이트 확인 → 설치·업데이트**로 받을 수 있다. 사용자의 실제 게임 설치와 저장을 검증용 설치로 덮어쓰지 않았다.
