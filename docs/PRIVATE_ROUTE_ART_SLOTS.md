# 개별 루트 스탠딩·추후 일러스트 제작 위치

기존 일상복 스탠딩과 준비된 표정을 사용한다. CG/SD/휴대폰에는 스탠딩을 겹치지 않는다. 발화자 밝기·고정 크기는 기존 공통 기능을 사용한다.

로만 R06 `roman_obsess_01` / `roman_obsess_02`는 새 표정 제공 전까지 비운다. 시크릿 전용 의상도 일상복으로 대체하지 않는다. 이미 제공된 시크릿 CG는 유지한다.

일반 CG 예정 구간은 일상복 스탠딩을 계속 보여 주며 아래 콘티 위치에 추후 그림을 연결한다. 이번 작업에서 새 일러스트를 생성하지 않았다.

## 갱신 순서

대사·엔딩·휴대폰 줄 위치 편집 후 `tools/build_private_route_staging.py`를 마지막에 실행한다. 원고는 고치지 않는다. 배포된 `.rpyc`의 정확한 대사/선택지 위치로 동작하므로 `.rpy` 원문 파일은 필요 없다.

API: `private_route_stage_lookup(filename, line)`, `private_route_standing_refresh()`. 지원하지 않는 파일/줄의 위치를 추측하지 않는다.
