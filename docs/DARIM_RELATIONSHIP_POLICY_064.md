# 다림 D01~D06 호감도·엔딩 정책 · 0.6.4

정책은 `D:/CampusRomance_VN/renpy_project/game/data/darim_relationship_choices.json`, 판정은 `game/systems/darim_relationship_policy.rpy`에 있다. 기존 호감도 엔진이 카탈로그를 읽으며, 별도의 `darim_happy`, `darim_bad` 누적 변수를 만들거나 원고의 예시 대입문으로 이중 보상하지 않는다. 신뢰도는 사용하지 않는다.

## 원고와 점수

고정 원고 `design_docs/story_sources/darim_d01.txt`~`darim_d06.txt`에서 실제 선택 본문을 대조했다. 메뉴16개·옵션52개이며, D01 6개 / D02 6개 / D03 9개 / D04 10개 / D05 14개 / D06 7개다. 실제 효과34개는 해피,14개는 배드,4개는 무보상이다. 증가값은 오직5/10이고 무보상은 두 딕셔너리가 비어 있다.

| 장 | 해피 원시 최대 | 배드 원시 최대 |
| --- | ---: | ---: |
| D01 | 15 | 0 |
| D02 | 20 | 10 |
| D03 | 25 | 0 |
| D04 | 25 | 20 |
| D05 | 30 | 25 |
| D06 | 15 | 15 |
| 합계 | 130 | 70 |

최대값은 각 색별로 따로 고른 수치이며 한 플레이에서 두 최대를 동시에 얻는다는 뜻이 아니다. 기존 게이지는100상한이다. 점수 상한 때문에 행동 이력이 사라지지 않도록 엔딩은 실제 선택 기록도 함께 본다.

다음 선택은 원고 그대로0점이다. 다른 취향이나 일반 문의를 통제로 확대 해석하지 않았다.

- D01 협동 게임 전부 맡기기(C), 유능한 선배라는 기대 표현(C).
- D03 원래 일정으로 돌아가자(C).
- D05 공개 페이지에서 프로그램의 일반 안전 정보를 문의하기(선택02 C): 신청 변경·무단 취소가 실제로 발생하지 않는다.

D03 고백의 세 표현은 전부 해피10이며, 표현 취향 때문에 임의의 배드 점수를 주지 않는다.

## 판정에 쓰는 실제 근거

현재 플레이의 `choice_log`에 있고 실제 카탈로그로 보상 처리한 ID만 사용한다. 같은 메뉴를 여러 번 만났으면 최신 답을 근거로 사용한다. 중복 ID는 점수를 다시 합산하지 않는다. 예전 애정·신뢰도 합계나 `persistent`의 다른 회차 기록으로 누락된 행동을 추측하지 않는다. 공통 루트는 그 선택에서 **다림에게 직접 귀속된 부분**만 포함하고 다른 히로인 점수는 합산하지 않는다.

주요 ID는 다음과 같다.

| 장면 | 메뉴 ID | 긍정 A/B | 통제·압박 C/D |
| --- | --- | --- | --- |
| D04 배려와 통제 | `darim_d04_choice03` | 인정·먼저 묻기 | 대신 결정·감정 묵살 |
| D05 리허설 일정 | `darim_d05_choice03` | 존중·협의 | 동행 강요·허락 요구 |
| D05 핵심 선택 | `darim_d05_choice04` | 통제 인정·불안 다루기 | 통제 정당화·정서 압박 |
| D06 최종 선택 | `darim_d06_choice02` | 자율성 존중·불안 소통 | 통제 정당화·죄책감 압박 |

### 배드

다음 조건이 모두 필요하다.

1. D06 최종 답이C/D.
2. D05 핵심 답이C/D이고 `darim_d05_conflict_resolved`가False.
3. 그 이전에도 미해결 D04 핵심C/D 또는 D05 리허설C/D가 있었음.
4. 실제 다림 배드 점수가30이상이고 D05의 실제 회복 완료가 없음.

즉 서로 다른 주요 메뉴에서 실제10점짜리 통제가 적어도3회 반복되어야 한다. D04가 건강했더라도 D05의 동행/허락 강요→통제 정당화→D06의 재확인은 반복된 통제로 판정한다. 반대로 잘 쌓은 관계에서 마지막 부정 답 하나만 고른 경우는 즉시 배드로 보내지 않는다.

### 해피와 혼합 상태

D05 핵심A/B, 실제 갈등 해결True와 대화 완료True, D06 최종A/B, 해피30이상이면 해피 경로다. 그 외 배드 조건이 아닌 상태는 `recover`로 원문 SC05-H에 들어간다. 마지막 긍정 답 한 번으로 이전 일을 즉시 지우지는 않는다.

원문 SC05-H에는 다른 결정을 해도 괜찮다고 말하기, 손잡고 싶지 않은 날의 거절 존중, 각자의 게임 약속과 가능한 시간을 고려해 함께 일정을 정하는 실제 행동이 있다. 원문 `darim_d06_mutual_schedule=True` 실행 뒤에만 `darim_confirm_recovery()`가 회복 완료를 기록한다. 점수를 추가하거나 배드 게이지를 낮추거나 과거 갈등 플래그를 덮어쓰지 않는다. H05 완료 전에는 혼합 상태를 해피 완료로 기록하지 않는다. 배드 경로에서 이 확인 함수를 잘못 부르면False다.

모든 경로에서 다림이 직접 학술 프로젝트를 신청·발표한 사실과 본인의 거절·의견을 보존한다. 통제적 배드 관계를 이상적인 사랑으로 바꾸지 않고, 원문의 시간 경과와 다림의 마지막 질문을 그대로 둔다.

시크릿 애프터 「선배의 특별 레시피」는 D06의 후속 예고이며 이번에 별도 원고가 없으므로 새 시크릿 본문·점수 정책은 만들지 않았다.
