CH06의 다른 SD 제작 지시는 실행되는 이미지 호출 없이 기존 스탠딩으로 진행한다. 기존 SD 시스템과 다른 챕터 에셋은 유지한다.

## 스탠딩 확인

CH06의 배경 전환 39곳 중 현장에서 캐릭터와 만나는 34곳에 이미 스탠딩이 연결되어 있다. 나머지 5곳은 주인공 방, 혼자 축제에 도착하는 장면, 완성된 전시를 혼자 살펴보는 장면, 헤어진 뒤 휴대폰을 보는 산책로 등이다. 그곳에 대면 스탠딩을 추가하지 않았다.

여러 인물이 포함된 출연 명단은 기존 화면 분할 규칙을 사용한다. 히로인 5명과 라이벌 4명을 동시에 한 화면에 작게 줄여 놓지 않는다. 일러스트가 표시되는 동안 `story_stage(faces=...)`는 기존 보호 로직에 의해 그림을 끄거나 스탠딩을 덧붙이지 않는다.
