# 공통 루트 CH01~CH07 스탠딩 · 0.6.2-test

기준 원본은 `D:\CampusRomance_VN\renpy_project`다. 시아 전체 스토리 0.6.1의 공개·검증을 먼저 마친 후 사용자 요청에 따라 공통 루트 스탠딩을 보완했다.

## 반영 범위

- CH01~CH05는 기존 히로인/라이벌 스탠딩, 첫 등장, SD/LD 전환을 점검해 유지했다. CH03 SC04의 돌아온 방문객만 빠져 있어 기존 방문객 이미지를 추가했다. 히로인 다섯을 왼쪽에 겹쳐 두고 방문객이 오른쪽에서 등장·퇴장하는 기존 SC03 구도를 사용한다.
- CH06은 39개 배경 중 실제 대화가 있는 34곳, CH07은 23개 배경 중 12곳에 스탠딩을 추가했다. 모두 46곳이다.
- 다섯 히로인, 네 라이벌, 개인 이벤트의 한 명을 실제 현장에 있는 인원에 맞춰 배치한다. 히로인/라이벌 아홉 명의 논리적 캐스트는 기존 팀별 화면으로 나누어 표시한다. 방문객은 기존처럼 다섯 히로인의 옆에 별도 자리로 배치한다.
- 기존 폭872의 가까운 구도와 화자 밝기/다른 인물 어둡게 표시를 유지했다. 누가 들어올 때 다른 인물의 크기를 줄이지 않는다. 오므는 기존 `direct` 기본 표정과 등록된 표정 파일을 사용한다.
- CH06 초반 시아·오므 도착, 마지막 동아리실 라이벌 도착에 등장 동작을 넣었다. 문밖 협합의 한마디에서는 현재 보이는 다섯을 유지하고 협합 이미지는 실제 입장 때 나타난다.
- 원문 감정에 맞춘 표정·등장 등166개 지점과 장소 진입의 부드러운 표시를 연결했다. 대사나 선택, 점수 처리를 바꾸지 않았다.

## 그대로 둔 장면

휴대폰 초대/대화, 혼자 걷거나 회상하는 독백, 텅 빈 부스 묘사에는 인물을 억지로 띄우지 않는다. 기존 SD/CG 표시 중에는 스탠딩이 겹치지 않도록 기존 시스템을 유지한다. CH06·CH07의 미제작 SD/CG 지시는 콘티 그대로이며 새 그림을 만들지 않았다. 익명의 여러 방문객도 별도 새 외형을 만들지 않았다.

공통 장면 helper는 명시적으로 `cast`와 `standing=True`를 준 경우에만 켜진다. 기본 `standing=False`를 유지하여 로만·시아 개인 루트의 콘티 상태를 변경하지 않았다.

## 실행·저장·공개 결과

**실제 Ren'Py 19개 케이스·52개 SDK 검증·28개 확인 지점 통과.** CH06 첫3명→시아·오므 도착, 히로인/라이벌 팀 화면, 문밖 음성과 실제 입장, 하린 회상과 복귀, 다섯 CH06 개인 이벤트, 다섯 CH07 초대→실제 만남, 최종 선택 확인/취소, CH03 방문객 구도·누락 에셋의 안전한 fallback, 휴대폰·SD·CG 중 스탠딩 억제를 확인했다. 대표 화면도 직접 검수했다.

공통 대사·선택7,126개는 백업과 정확히 같고 CH06/07 연출 제거 후의 전체 원문 투영도 같다. source477개와 검증 복사본의 SHA가 전부 같으며 실제 사용자 저장14개의 SHA·수정 시간이 유지됐다. 공식 SDK 컴파일과 Lint를 통과했다. 최종Lint는 오류 없이 종료했다. 원본 게임이나 사용자의 실제 저장을 실행하지 않고 D의 격리 사본과 SDL dummy/software 표시를 사용했다. 실제 GPU 렌더링이나 모든 플레이 조합을 전수 검사했다고 주장하지 않는다.

새 CH06 저장/불러오기, 실제 공개0.6.1의 시아 S03 저장과 CH06 저장을 새 버전으로 불러오는 검사를 통과했다. 시아는 동일 대사 노드·점수·폰·개인 루트의 스탠딩 없음이 유지됐다. CH06도 대사 위치·점수·선택·파트너·폰이 유지됐다.

**확인된 표시 한계:** 구 CH06 저장은 당시 `standing=False` 배치 상태도 그대로 저장되어 있다. 대표 첫 부스 저장을 불러오면 현재 대면 장면은 빈 상태이며, 다음 배경에서 새9명 논리 캐스트/히로인5명 화면·폭872가 정상 활성화된다. 진행 데이터 손실은 없다. 옛 장면을 추측해 강제로 재배치하는 마이그레이션은 넣지 않았다. 새 챕터 선택/신규 진행에서는 즉시 새 배치를 볼 수 있다.
