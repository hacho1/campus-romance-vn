## 화면과 이동

휴대폰은 화면 중앙의 스마트폰 프레임으로 표시합니다. 흰색·연회색 바탕, 원형 프로필, 좌우 말풍선과 작은 시각 표시를 사용합니다. 특정 메신저의 로고·상표·화면을 복제하지 않는 게임용 메시지 UI입니다.

| 화면 | 표시하는 정보 | 이동 |
| --- | --- | --- |
| 대화방 `chat` | 방 이름, 개인/단체 구분, 발신자·원형 프사, 날짜, 메시지·시각 | 헤더의 채팅 목록 또는 잠금화면 |
| 채팅 목록 `list` | 방 이름, 마지막 메시지, 시각, 안 읽은 수 | 방을 누르면 해당 대화방, 잠금화면 버튼으로 잠금화면 |
| 잠금화면 `lock` | 큰 시계·날짜·배경·메시지 미리보기 | 알림 열기 → 해당 대화방. 채팅 목록은 별도 버튼 |

별개의 메시지 이벤트는 알림을 직접 눌러 읽습니다. 이미 읽는 중인 단체방에서 같은 장면의 개인방으로 이어지면 휴대폰을 열린 채로 유지합니다. 수신 메시지는 왼쪽, 플레이어 메시지는 오른쪽에 표시합니다. 단체방은 메시지마다 발신자 이름과 프사를 보여 줍니다. 기록이 길어지면 대화 영역을 스크롤할 수 있습니다. 긴 답장 후보도 별도 답장 영역에서 스크롤하며 원래 선택지 문장을 생략하지 않습니다. 긴 방 제목은 좁은 목록·헤더에서만 말줄임하고 전체 제목을 툴팁·접근성 이름에 유지합니다.

진행 중인 대화방에서는 `다음 메시지`로 기존 네이티브 대사를 넘깁니다. 잠금화면·목록·다른 대화방을 읽을 때에는 본편 대사가 임의로 넘어가지 않도록 합니다. 다른 방을 보다가 `진행 중인 대화로`를 누르면 현재 이벤트로 돌아갑니다. 일반 장면의 퀵메뉴에는 이미 받은 대화를 다시 보는 `휴대폰` 항목이 표시됩니다. 여기서 닫기는 본편으로 복귀합니다.

휴대폰 대화 중 주인공의 독백(`narrator`)은 일반 장면과 같은 **화면 하단 대사창**에 표시합니다. 휴대폰 옆에 독백 말풍선을 따로 띄우지 않습니다. 휴대폰 프레임은 그대로 유지하며, 독백을 채팅 메시지로 추가하지 않습니다. 실제 수신 메시지와 주인공이 보낸 답장은 계속 휴대폰 안의 말풍선으로 표시합니다. 대화창을 벗어나 잠금화면·목록·다른 방을 보는 동안의 진행 제한은 기존과 같습니다.

2026-11-07 독백 표시 변경은 CH01 실제 장면·개인/단체방·저장/불러오기·진행 제한을 포함한 네이티브 검사 2개(검증문 40개)와 Lint를 통과했습니다. 하단 창은 실제 렌더링에서 `(60, 814, 1800, 235)` 영역으로 확인했습니다. [독백 대사창 검증 기록](../tests/phone_narration_20261107/README.md)에 화면·수정 파일·백업 위치를 정리했습니다.

## 본편 연결과 답장

기존 대본의 `$ story_chat(True, title="...")`가 `phone_begin(title)`에 연결됩니다. 메시지 이벤트를 종료할 때에는 기존대로 `$ story_chat(False)`를 사용합니다. 대본을 별도 문자열 재생기로 바꾸지 않고 Ren’Py `say`·`menu`·저장·기록을 그대로 사용합니다.

```renpy
$ story_chat(True, title="로만과의 대화")
roman "기존 대본의 메시지를 여기에 유지합니다."
mc "기존 플레이어 답장을 유지합니다."
$ story_chat(False)
```

제목에 히로인 이름이 들어가면 해당 개인방(`private_roman` 등)으로, 그 외에는 단체방(`campus_group`)으로 묶습니다. 기존 채팅 구간의 대사 콜백이 `phone_record(actor, text)`를 호출합니다. 같은 메시지를 화면 갱신·불러오기 때문에 중복으로 더하지 않도록 위치 키를 기록합니다.

네이티브 `menu`가 실제로 있는 휴대폰 장면에서는 선택지가 입력창 위의 답장 후보로 표시됩니다. 선택지의 원래 action과 결과를 사용하므로 호감도·플래그 처리를 별도로 복사하지 않습니다. **현재 본편의 고정 메시지에 답장 선택지를 새로 추가하지 않았습니다.** 개발 전용 `phone_ui_preview` 라벨은 세 답장을 눌러 보는 별도 시연입니다. 이 시연은 본편 사건·호감도·엔딩 기록을 만드는 콘텐츠가 아닙니다.

## 코드와 데이터

| 파일 | 역할 |
| --- | --- |
| `game/systems/phone_system.rpy` | 방과 메시지 상태·화면 전환·중복 방지·불러오기 이관 |

| `game/screens_phone.rpy` | 잠금화면·목록·대화방·답장·원형 프사·휴대폰 안팎 읽기 UI |

주요 API는 `phone_begin(title)`, `phone_record(actor, text, legacy_key=None)`, `phone_set_view(view, thread=None)`, `phone_migrate_after_load()`입니다. 새 API를 대본의 모든 대사에 수동으로 중복 삽입하지 말고 기존 `story_chat` 구간을 우선 사용하세요.

## 저장 상태와 수집 기록

`phone_threads`, 활성/선택 방, `phone_view`, 메시지 순번·날짜·시각은 **현재 세이브의 상태**입니다. 메시지는 actor, name, text, time, date, key를 가집니다. 채팅 목록은 마지막 갱신 순서로 정렬하고, 현재 보지 않는 방의 수신 메시지는 안 읽은 수로 표시합니다. 방을 열면 그 방의 수가 0이 됩니다.

대화 이력은 `persistent`의 전 회차 수집함이 아닙니다. 다른 세이브를 불러오면 그 세이브의 대화를 보여 줍니다. CG·SD 갤러리의 영구 수집 기록과 구분합니다. 구 저장의 `story_chat_messages`가 남아 있고 새 phone 스키마가 없으면 불러오기에서 그 기록을 새 방으로 옮깁니다. 구 형식이 최근 메시지만 보관했다면 그보다 오래된 대화를 새로 복원해 만들지는 않습니다.

휴대폰 메시지·발신자·시각·버튼은 `CAMPUS_BODY_FONT`의 Noto Sans KR를 사용합니다. `CAMPUS_TITLE_FONT`는 Noto Serif KR이며 개구 Regular는 작은 장식 손메모에만 씁니다. 경로는 `game/typography.rpy`에서 바꿉니다. 세 상수는 init -200에, 공통 스타일은 init 999에 정의합니다. 원본 폰트와 OFL 고지는 `game/fonts/`에 있고, 기존 폰트 파일을 삭제하지 않습니다.

## 프사와 배경 교체

히로인 ID는 `roman`, `sia`, `darim`, `omu`, `lumi`를 사용합니다. 하린의 표시 탭은 HARIN지만 기존 내부 ID는 `lumi`입니다. 프사는 아래 순서로 찾습니다.

1. `game/images/heroines/profile_<id>.png`
2. `game/images/heroines/<id>/profile.png`
3. `game/images/heroines/<id>/profile.webp`

정사각형 그림에 얼굴 주변 여백을 충분히 남겨 주세요. 원형 마스크로 잘라 표시하므로 모서리의 중요한 장식은 보이지 않을 수 있습니다. 파일이 없으면 이름 글자가 들어간 원형 대체 프사를 사용합니다. 주인공의 얼굴·성별·외형을 확정하는 그림은 만들지 않습니다.

`phone_ui.json`의 `wallpaper`는 `images/ui/phone/wallpaper.webp`를 가리킵니다. 해당 파일이나 같은 이름의 PNG를 넣으면 잠금화면에 적용합니다. 설정한 경로와 같은 이름의 PNG/WebP가 모두 없으면 기존 `images/backgrounds/campus.png`를 연하게 표시합니다. 배경만 바꿔도 시계·알림을 읽을 수 있도록 낮은 대비와 단순한 구도를 권장합니다.

날짜와 시각은 교체 가능한 **연출용 기본값**입니다. 운영체제의 실제 시계나 대본의 확정 연대를 뜻하지 않습니다. 챕터별 값은 `phone_ui.json`의 `chapters`에서 수정합니다. 시간 표기를 바꾸며 원문 사건의 순서를 임의로 고치지 마세요.

## 검증 범위

이 문서는 구현 파일과 데이터의 사용 안내입니다. 잠금→알림→목록→대화 이동, 개인/단체 좌우 말풍선, 미읽음 배지, 세 답장, 이전 메시지 스크롤, 저장·불러오기와 기록·자동 진행, 작은 창에서 한글 줄바꿈의 최종 실행 결과는 [0.3.0 검증 기록](../tests/VERIFICATION_0.3.0.md)을 기준으로 확인합니다. 최종 캐릭터 프사와 잠금 배경 원화는 이번 작업에서 생성하지 않았습니다.
