# 우리 사이, 그 이상: 설치 페이지 디자인 계약

## 목적과 범위

이 페이지는 한 게임의 Windows 런처를 내려받고, 게임을 알아보고, 배포 버전을 확인하는 제품 페이지다. 게임 실행은 설치한 PC 클라이언트가 맡는다. 가격·구매·리뷰·다른 게임·계정·클라우드 저장은 이 페이지 범위에 없다.

## 주제의 재료

- 게임 이름: 우리 사이, 그 이상
- 배경: CC대의 봄과 축제 준비
- 다섯 사람: 로만, 시아, 다림, 오므, 하린
- 원본 타이틀 아트: 다섯 사람이 봄꽃 위에 나란히 누운 장면
- 프로필: 사진과 비밀 메모가 담긴 노트
- 축제에서 만난 학생들: 스키, 협합, 밤밤, 헤스
- 이번 게임 범위: CH01–07 공통 루트, 로만 R01–R06의 해피·배드 엔딩과 해피 이후 시크릿
- 게임의 기준 원본: D 드라이브의 Ren'Py 프로젝트
- 배포 방식: Windows에 런처 설치 후 같은 클라이언트에서 갱신
- 현재 접근 상태: 공개 제품 페이지와 PC 런처 업데이트 채널

## 페이지의 주장과 근거

1. 다섯 사람과 축제를 준비하는 PC 비주얼 노벨이다. → 원본 단체 아트, 게임 제목, Windows 다운로드.
2. 선택과 기록으로 인물들을 알아간다. → 실제 프로필·메모와 학생 소개 화면.
3. 런처를 한 번 설치해 실행하고 이후 파일을 갱신한다. → 다운로드와 실제 설치 순서를 설명한다.
4. 지금 배포된 내용을 확인할 수 있다. → 실제 `releases/latest.json`의 버전·빌드·변경 사항을 읽는다.

## 방향과 아이디어

`design-taste-frontend`에서 The split stage를 선택했다. seed는 `329477076`이다. 다른 후보는 contact-sheet와 uneven-photographs였다. 게임은 하나이며 여러 작품의 썸네일 목록이 필요하지 않아, 다섯 사람의 아트가 머무는 분할 구성이 적합하다.

이 페이지에서는 **다섯 사람이 나란히 누운 봄의 단체 그림**이 **소개를 읽는 동안 함께 머무는 고정 장면**이 된다. 그림을 사람별로 잘라 쓰지 않고 전원을 함께 보여준다. 설치 안내부터는 분할을 풀어 제품 이용 방식으로 초점을 옮긴다.

한 가지 살아 있는 요소는 실제 게임 화면 선택과 크게 보기다. 첫 화면, 우리의 페이지, 만난 사람들을 직접 선택해 볼 수 있다. 스크립트가 없을 때는 기본 화면과 나머지 원본 이미지 링크를 제공한다.

페이지는 주어진 실제 아트를 사용한다. 방향 시트의 건축 사진과 사진 검색 제안은 사용하지 않았고 재추첨도 하지 않았다. 장식용 사진·새 그림·거짓 화면을 추가하지 않았다.

## 구조와 반응형 계약

- 1280px: 읽기 면과 고정 아트 면이 절반씩 놓인다. 소개와 화면 선택은 왼쪽, 전체 단체 아트는 오른쪽에 남는다.
- 768px: 단체 아트가 먼저 나오고 읽기 면이 이어진다. 설치와 배포 안내는 두 열이다.
- 390px: 아트, 제목, 다운로드 순서로 한 열이 된다. 설치·배포 안내도 한 열이다. 화면 선택 버튼 3개는 모두 보이고 옆 스크롤을 요구하지 않는다.
- 제목은 두 줄 이내, 실제 이미지에 텍스트를 겹치지 않는다.
- 화면 크게 보기는 네이티브 `dialog`를 사용하며 Escape와 닫기 버튼으로 돌아간다.
- 키보드 포커스는 3px 외곽선으로 드러난다. 모든 주요 조작의 최소 높이는 44px이다.

## 동작과 진실성

- 다운로드: `downloads/CampusRomanceLauncher.exe`에 HEAD 요청을 보낸다. 성공한 실제 파일일 때 링크를 활성화한다. HTML로 돌아오는 SPA fallback과 404는 준비 중으로 표시한다.
- 버전: `releases/latest.json`만 읽고 버전·빌드·변경 사항을 표시한다. 게임 파일 목록이나 청크는 브라우저에서 내려받지 않는다.
- 오류: 로딩, 성공, 조회 실패와 다시 확인을 구분한다. 실패 때 가짜 최신 버전이나 빈 성공 상태를 표시하지 않는다.
- 내용 범위: 로만 외 네 사람의 개별 루트는 제작 중임을 명시한다. 공통 7장의 모든 개인 데이트나 다섯 개별 루트가 완성됐다고 안내하지 않는다. 시크릿 CG는 게임 내 해금용으로만 유지하고 페이지에 추가하지 않는다.
- 모션: 단체 그림의 작은 확대, 화면 선택 시 짧은 불투명도 전환, 각 구역의 짧은 최초 진입과 조작 피드백을 사용한다. 내용은 스크립트 실행 전에도 보이며 reduced motion에서는 이동과 전환을 제거한다.

## 검증

JS 구문 검사와 taste source lint: PASS, 0 FAIL / 0 WARN. 실제 headless 브라우저의 1440/1280/768/390 검사: 0 FAIL. 실제 게임 영상이 없는 `no-footage` 경고 1개는 원본 아트와 지정된 게임 화면을 사용한 선택으로 기록한다. 모든 최종 fold와 전체 페이지 스크린샷을 직접 확인했다. 최종 화면 비평 점수는 7.6이며 세 차례 기록과 검사 결과는 `.taste-skill`에 있다. 런처 EXE와 배포 manifest는 root가 넣는 실제 산출물로 마지막 연결 검증을 수행한다.
